# Personal Portfolio

My personal portfolio website — showcasing projects, skills, and certifications.

## 🌐 Live Site
[https://tchoga.netlify.app](https://tchoga.netlify.app)

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript

## ✨ Features
- Dark / light mode toggle (with saved preference)
- Terminal-inspired design with monospace font
- Typing animation on the hero tagline
- Scroll reveal animations
- Fully responsive (mobile / tablet / desktop)
- Downloadable CV

## 🚀 Deployment
Deployed on [Netlify](https://netlify.com).
